## 🚀 Quickstart & Usage

### 1. Clone the Repository
```bash
git clone https://github.com/VarshuAi/go-load-balancer.git
cd go-load-balancer
```

### 2. Execution
Build and run:
```bash
go run main.go
# Or compile binary:
go build -o go-load-balancer .
./go-load-balancer
```
